# Drop your photos & logos here

Name the file exactly as listed below (the **base name** — the extension can be
anything: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, …). As soon as a file is
here, it replaces the matching placeholder on the site automatically. No code
changes needed.

> Tip: standard web formats (`.jpg`, `.png`, `.webp`) load fastest. Phone
> formats like `.heic` may not display in all browsers — convert to `.jpg`
> first if you can.

---

## Logos

| File name        | Where it shows         | Notes                                  |
| ---------------- | ---------------------- | -------------------------------------- |
| `logo-landscape` | Header + footer        | Graphic **+ text**, wide. Shown ~40px tall. |
| `logo-square`    | (reserved)             | Graphic only. Keep handy for favicon/social. |

If no `logo-landscape` file is present, a clean built-in "Stingray" wordmark is
shown instead, so nothing breaks.
